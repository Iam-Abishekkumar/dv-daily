# Q001 - sv

What is the difference between logic, wire and reg in SystemVerilog?


**My answer:**

          A net type used to connect hardware signals. It is commonly used with continuous assignments (`assign`).
          A Verilog variable used for procedural assignments inside `always` or `initial` blocks. It does not necessarily represent a hardware register.
           A SystemVerilog variable type that replaces `reg` in most cases. It can be used in procedural blocks and with continuous assignments when appropriate.

           `wire` is a net, whereas `reg` and `logic` are variable types. The hardware inferred depends on the coding style, not just the data type.
