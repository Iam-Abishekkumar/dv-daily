# Q003 - sva

**Question:** Immediate assertion vs concurrent assertion: what is the difference?

**My answer:**
Q3. What is the difference between immediate assertion and concurrent assertion?

Answer:

Immediate Assertion:
- Evaluated immediately when the statement executes.
- Used inside procedural blocks like always, initial, and tasks.
- Checks a condition at that moment.
- Syntax: assert (condition);

Example:
```systemverilog
always_comb begin
    assert (a <= 10)
        else $error("Immediate assertion failed");
end
```

Concurrent Assertion:
- Evaluates a property over time, usually synchronized with a clock.
- Uses SystemVerilog Assertion (SVA) syntax.
- Checks behavior across clock cycles.
- Syntax: assert property (@(posedge clk) property_expression);

Example:
```systemverilog
assert property (@(posedge clk)
    req |-> ##1 gnt
) else $error("Concurrent assertion failed");
```

Key Difference:
Immediate assertions check a condition when procedural execution reaches them, whereas concurrent assertions check time-based behavior, typically across clock cycles.
