# Q002 - uvm

**Question:** Describe the UVM testbench hierarchy: test, env, agent, driver, monitor, sequencer, scoreboard.

**My answer:**
Q2. Describe the UVM testbench hierarchy: test, env, agent, driver, monitor, sequencer, scoreboard.

Answer:

A UVM testbench is organized hierarchically to make verification reusable and modular.

- Test: The top-level component that configures and controls the verification environment.
- Environment (env): Contains agents and the scoreboard.
- Agent: Groups the driver, monitor, and sequencer. It can be active or passive.
- Sequencer: Sends sequence items from sequences to the driver.
- Driver: Converts sequence items into pin-level signals and drives the DUT.
- Monitor: Observes DUT signals and converts them into transactions for checking.
- Scoreboard: Compares actual DUT results against expected results.

Typical hierarchy:

test → env → agent → driver, sequencer, monitor

The scoreboard is usually instantiated inside the environment and receives monitored transactions.

Key Point: The driver drives signals, the monitor observes signals, the sequencer provides transactions, and the scoreboard checks correctness.
